## Features

> `npm i @pardnchiu/renderjs` · [Documentation](./doc/doc.md)

- **Chainable DOM Construction** — Build real DOM elements straight from tag-selector strings instead of verbose createElement chains.
- **One-Shot Template Engine** — Declarative directives render into the DOM in a single pass, with no virtual-DOM diffing or reactive watching, so you decide exactly when the view updates.
- **Native Prototype Extensions** — Dozens of chainable methods on String, Array, Object, Element, URL, and window cover element queries, requests, query strings, and cookies.
- **Built-in Lazyload and SVG Inlining** — One call enables IntersectionObserver-driven image lazy loading and automatic inlining of external SVG files.
- **Zero-Dependency Single File** — One minified file runs directly in the browser, installed via npm or a CDN script tag.
